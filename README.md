# Голосовой Ассистент Яша

Яша — это голосовой ассистент, разработанный для Финансового Университета при Правительтве РФ, предназначенный для обработки голосовых команд на русском языке и ответа с использованием синтезированной речи. Создан на Python с интеграцией распознавания речи, обработки естественного языка через Yandex GPT и синтеза текста в речь. Ассистент поддерживает распознавание команд, генерацию ответов и прерывание по стоп-словам, что делает его интерактивным и удобным для пользователей.

## Особенности

- **Распознавание голосовых команд**: Слушает команды пользователя на русском языке с помощью распознавания речи.
- **Обработка естественного языка**: Обрабатывает команды через Yandex GPT для создания умных ответов.
- **Синтез речи**: Отвечает синтезированной речью с использованием Yandex SpeechKit.
- **Поддержка стоп-слов**: Позволяет прерывать ответы с помощью заранее заданных стоп-слов (например, "стоп", "хватит").
- **Гибкая настройка**: Настраиваемые имя ассистента, голос и стиль ответов.
- **Логирование**: Записывает все взаимодействия и ошибки в консоль и ежедневные лог-файлы.

## Требования

- Python 3.8 или выше
- Аккаунт Yandex Cloud с доступом к API для GPT и SpeechKit
- Установленный FFmpeg (для обработки аудио)
- Рабочий микрофон

## Установка

1. **Клонируйте репозиторий**:

   ```bash
   git clone https://github.com/lolopogff/Yasha
   cd Yasha
   ```

2. **Создайте виртуальное окружение**:

   ```bash
   python -m venv venv
   source venv/bin/activate  # Для Windows: venv\Scripts\activate
   ```

3. **Установите зависимости**: Установите необходимые Python-пакеты, перечисленные в `requirements.txt`:

   ```bash
   pip install -r requirements.txt
   ```

   Убедитесь, что `requirements.txt` содержит:

   ```
   pygame
   speechrecognition
   requests
   speechkit
   ```

4. **Установите FFmpeg**:

   - На Ubuntu: `sudo apt-get install ffmpeg`
   - На macOS: `brew install ffmpeg`
   - На Windows: Скачайте с сайта FFmpeg и добавьте в PATH.

## Настройка

1. **Настройте учетные данные Yandex Cloud**:

   - Получите `FOLDER_ID`, `API_KEY` и `IAM_TOKEN` в Yandex Cloud.

   - Обновите класс `Settings` в `config.py` с этими значениями:

     ```python
     class Settings:
         FOLDER_ID = "ваш_folder_id"
         API_KEY = "ваш_api_key"
         IAM_TOKEN = "ваш_iam_token"
     ```

2. **Настройте параметры ассистента**:

   - Измените класс `Info` в `config.py` для настройки имени, голоса или поведения ассистента:

     ```python
     class Info:
         NAME = "Яша"  # Имя ассистента
         VOICE = "kirill"  # Голос для синтеза
         VOICE_STYLE = "good"  # Стиль голоса
         DESCRIPTION = "..."  # Системная инструкция для Yandex GPT
         CONCLUDING_PHRASES = ["пока", "до свидания"]  # Фразы для завершения
         STOP_PHRASES = ["стоп", "хватит"]  # Фразы для прерывания
     ```

## Использование

1. **Запустите ассистента**:

   ```bash
   python main.py
   ```

   Ассистент приветствует вас фразой "Привет! Чем могу помочь?" и начинает слушать команды.

2. **Взаимодействуйте с Яшей**:

   - Произнесите команду четко (например, "Расскажи о погоде").
   - Яша обработает команду через Yandex GPT и ответит синтезированной речью.
   - Чтобы прервать ответ, произнесите стоп-слово, например "стоп".
   - Чтобы завершить работу, скажите фразу, например "пока".

3. **Логи**:

   - Проверяйте логи в папке `logs/` (например, `logs/Яша_2025-05-15.log`) для отладки или мониторинга.

## Структура проекта

- `main.py`: Основной скрипт, который запускает ассистента, обрабатывает команды и генерирует ответы.
- `promt.py`: Отвечает за взаимодействие с Yandex GPT для генерации текстовых ответов.
- `answer.py`: Преобразует текстовые ответы в синтезированную речь с помощью Yandex SpeechKit.
- `config.py`: Содержит настройки, включая информацию об ассистенте и учетные данные API.
- `logger.py`: Настраивает логирование в файл и консоль для отладки и мониторинга.
- `logs/`: Папка для ежедневных лог-файлов (создается автоматически).
- `requirements.txt`: Список зависимостей Python.

## Логирование

- Логи сохраняются в папке `logs/` с именами файлов вида `Яша_ГГГГ-ММ-ДД.log`.
- Формат логов: `временная_метка - уровень - сообщение`.
- Уровни включают INFO, DEBUG и ERROR для отслеживания взаимодействий и ошибок.
- Логи также выводятся в консоль для мониторинга в реальном времени.
